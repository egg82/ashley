source (home_assistant/client.py, connected_homes.py, ha_socket.py) and the suite run whole (-x, two xdist workers); "caught" is a
failing run. Each file was restored from the text read before mutating, asserted equal after each. 41 planted: 37 caught (7 only

listening is unavailable (M20); a greeting that is not auth_required is unavailable (M21); a REST 401 and a 200 text/plain leave
checked_at (M34, M35); a REST read is one write (M36); a client with no stored connection moves nobody's (M40).
