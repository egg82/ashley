Equivalent or untestable
M76  By design only reads of a mailbox answer needs_reconnect; what `mail_boxes` shows for a connection that needs a reconnect
     is not stated, so the suite does not pin it (design gap, reported).
M24b A date rendered in a time zone other than UTC for a message sent at 12:00 UTC: the test message sits at midday so every
     zone within +-11 hours gives the same calendar day; a zone beyond that is untestable without pinning the format.
M99  The cap's value (25, 50, 100): the design makes it data (`mail.json`), so the suite pins only "capped, cut, paged
     to the end gives every match once".
M100 Fetching headers with `format=full` or `format=metadata`: equivalent through the tool's results; a count of attachments
     needs parts, which only `full` carries, so a test of the format would pin the adapter's route, not its contract.
M101 One mail.call per tool call or several per port call: the suite asserts at least one per tool call, not exactly one.

Verdicts (each mutant applied one at a time to the built code, run against this suite, the part's own mail tests and
mail_oauth_blind, per-run timeout 150 s; killed means the run went red)
Killed: M1-M9, M11-M15, M17-M75 (a letter suffix is a variant: M39a-f one dropped term each, M42a-b, M43a-b, M45a-b,
M64a-b, M83a-c, M93a-b; every variant killed), M77, M79, M82-M98. M78 is M2 (mail_search alone declaring outside false).
Killed by a directed test added for it: M88. A transport error on the search's list call, after the labels call answered,
is the only place query words are in hand when a failure is logged; the suite's failure test downed Gmail on the first call,
so a log of the request's query never saw them. test_mg_logs: a_search_that_cannot_reach_gmail_logs_no_query_words.
Equivalent (no test can tell them apart, with the reason):
M10  turn_tools  mail gated without the speaker check: `sources` returns nothing for a turn with no speaker_id before any
     source is built, so the check inside the mail gate is unreachable.
M16  turn_tools  mail offered when connections cannot be opened: MailTools' catalogue is empty then, because reading the
     person's connections raises ConnectionsUnavailable, and a call answers is_error; the offered set and every answer match.
M76  see above.
Not applied: M80 and M81 live in the turn's Outside check and the held-call summary (ashley.tools.outside and its callers),
outside this part's diff; this suite's taint tests pin them through the tools and ran green against the unmutated tree.
M89 was applied as an address that carried the access token (mail_boxes echoing a credential); M66 as a fixed stale token
where the renewed one belongs; M67, M69 and M74 were applied to ashley/connections/renewal.py, where those behaviours live.
