Planted mutants for the herdr bridge blind suite (app/tests/herdr_bridge_blind). Each was applied alone to the shipped
source in bridge/herdr/herdr_bridge and the whole suite run (-x, two xdist workers); "killed" is a failing run (an
xfail that starts to pass counts: strict). The file was restored from the text read before mutating, asserted equal after
each. 112 planted (one no-op control): 103 killed, 8 survived as equivalent or contract-silent (reasons below), the control
survived. A mutant that replaced the runner's argument list with a shell string was found to run the test arguments as
shell commands (it left empty files named by them in the working directory); the files were moved aside.
Directed tests were added for the first survivors: P04, P08, P13, I04, A12, P25, P27, H02, H04, H05, L04, C01-C03.
